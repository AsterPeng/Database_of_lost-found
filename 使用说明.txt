校园失物招领平台 —— 使用说明
========================================

一、怎么启动
  双击本文件夹里的「启动校园失物招领.bat」。
  启动完成后浏览器会自动打开 http://localhost:3000
  ★ 那个黑色命令行窗口不要关，关掉窗口就等于停止服务。

二、启动前提
  1. 本机已安装 Node.js 20 或更高版本（没有的话去 nodejs.org 下载）
  2. 本机 PostgreSQL 服务正在运行
     （服务名通常是 postgresql-x64-18，在「服务」里可以看到，一般开机自启）
  3. 端口 3000 没有被别的程序占用。被占用时可以换端口：
     在命令行里执行    启动校园失物招领.bat 3001
     然后访问 http://localhost:3001

三、登录账号
  管理员：admin@clfp.local    密码 Admin@12345
          （用管理员登录后，顶部会出现「管理后台」入口）
  学  生：student@clfp.local  密码 Demo@12345
  也可以直接点「注册」自己新建一个账号走完整流程。

四、这个文件夹里有什么
  src\          页面与业务代码（Next.js）
  prisma\       数据库结构定义、迁移脚本、初始数据脚本
  scripts\      测试脚本与向量化 worker
  docs\         需求文档与 PRD
  storage\      用户上传的图片
  node_modules\ 依赖包（约 688MB，可删除后自动重装）
  .env          数据库密码和加密密钥  ← 非常重要，丢了数据就打不开
  README.md     完整项目说明：技术栈、25 条需求实现明细、部署方法、常见问题
  使用说明.txt   本文件

五、关于体积与离线使用
  · 本文件夹已经包含依赖包 node_modules（约 688MB），双击启动脚本即可直接运行，
    不需要联网安装，适合演示前保管。
  · 如果你只需要保存代码、想把体积压到 1MB 以内，可以删掉 node_modules 文件夹，
    下次双击启动脚本时会自动重新安装（需要联网，约 1 分钟）。
  · 数据库本身不在这个文件夹里，它存在本机的 PostgreSQL 里。
    要单独备份数据，请执行：
      pg_dump -U clfp -h 127.0.0.1 clfp_dev > 备份文件.sql

六、几点注意
  · .env 里的 ENCRYPTION_KEY 一旦更换，已加密的手机号、认领联系方式
    将无法解密。备份时务必带上这个文件，也不要随意修改它。
  · 本文件夹是 C:\dsh\clfp 的完整副本，116 个代码文件已逐一校验一致
    （SHA256 比对，0 个不一致）。

七、换成另一台电脑怎么恢复
  1. 把本文件夹拷到新电脑
  2. 安装 Node.js 和 PostgreSQL
  3. 在新电脑上创建数据库和账号（用 psql 或 pgAdmin 执行）：
       CREATE ROLE clfp LOGIN PASSWORD 'clfp_dev_pw' CREATEDB;
       CREATE DATABASE clfp_dev OWNER clfp;
  4. 双击「启动校园失物招领.bat」，脚本会自动装依赖、建表
  5. 写入演示账号：在文件夹里执行  npm run db:seed
  6. 如果之前用 pg_dump 备份过数据，用 psql 恢复那个 .sql 文件

八、想自己改代码
  改完直接刷新浏览器就能看到（开发模式会热更新）。
  如果是给别人演示，建议先执行 npm run build 再 npm run start，
  打开速度更快、也不会因为改代码而中断。

九、想验证功能是否正常
  在文件夹里打开命令行，先确保服务已启动，然后执行：
      npm run verify:m1   （35 项单元测试：加密、脱敏、校验规则、免打扰时段）
      npm run verify:e2e     （241 项链路测试：注册、发布、匹配、认领、后台等）
