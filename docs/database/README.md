## 阅读顺序

1. 先读 01 了解业务实体与关系；
2. 再读 02 看关系模式如何满足范式；
3. 03 与 04 分别对应物理设计和字段级说明；
4. 05 是 P2 的实现清单，后续实验文档按阶段补充。

## 约定

- 文中“现状”指 P1 开始时数据库的真实结构，以 `db/sql/00_schema.sql` 和 `prisma/schema.prisma` 为准。
- 文中“P2 计划”指后续迁移要实现的对象，尚未落地，不应在答辩时当作已完成能力描述。
- 所有金额、成绩等敏感字段不涉及；用户手机号与认领联系方式采用应用层 AES-256-GCM 字段级加密，数据库只保存密文和脱敏值。
- 项目使用 Prisma 6.19.3 管理迁移，视图、函数、触发器、部分索引等无法在 `schema.prisma` 中表达的数据库对象，统一写入手写 SQL 迁移，保证 `prisma migrate` 可重复部署。
